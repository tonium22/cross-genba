# クロス現場帳（試作品 v0.1）

クロス職人用の現場管理アプリ。iPhoneのSafariで動くWebアプリ（PWA＝ホーム画面に追加するとアプリっぽく使えるWebページ）。

## できること

- 現場ファイル：作成・編集・削除・検索・ステータス（作業前／作業中／完了）・完了の表示切替
- クロス品番：1現場に何品番でも登録。メーカー・使用場所・仕入れ量・ロス設定
- 寸法表の読み取り：撮影 or 写真選択 → 無料OCRで読む（有料AIは許可制） → **確認画面で直してから保存**
  - 読めない数字は空欄＋「要確認」。取り消し線の行は「除外候補」でチェックが外れた状態
  - 同じ写真は二重登録できない。元の写真も保存される
- 糊付け済み／施工済みの管理：寸法ごとに ＋− で枚数を入れる
  - 糊付けした時点で「使用済み」。施工済みにしても二重に数えない
  - 必要・未糊付け・未施工・使用済み・残り・在庫残・不足 を別々に計算
- 注意事項メモ（写真・日付・ピン留め）、日報（作業内容・使用クロス・数量・ミス・写真）
- バックアップ（写真込みJSON）・CSV出力・復元、暗い現場用のダークモード

## 計算のルール

| 項目 | 計算 |
|---|---|
| 必要 | Σ(寸法＋1枚ロス)×枚数 ＋ 端材・予備 |
| 使用済み | 糊付け済み以上の枚数ぶん ＋ 手入力の使用記録 |
| 残り | 必要 − 使用済み |
| 未糊付け | まだ糊付けしてない枚数ぶん |
| 未施工 | まだ施工してない枚数ぶん（糊付け済みも含む） |

長さはmmの整数で計算して、表示の時だけmに直す（小数の誤差対策）。
テスト：`test.html` をブラウザで開くと15項目チェック。

## Macで動かす

```bash
cd cross-app && python3 -m http.server 8765
```

ブラウザで http://localhost:8765 を開く。

## 写真の読み取り（無料が基本）

- 標準は **無料OCR（Tesseract）**。APIキー不要、写真は端末の中で処理して外に送らない（初回だけ読み取り用データをダウンロード）
- 流れ：iPhoneの標準カメラで撮る → 写真アプリに保存 → アプリの「写真アプリから選ぶ」で取り込む → 一覧で確認・修正 → 保存
- 手書きが読みにくい時は、写真アプリの「テキスト認識」（文字を長押し→コピー）→ アプリの「文字を貼り付け」も無料
- 有料AI（Claude）は設定画面で本人がONにしてキーを保存した時だけ使う。初期設定はOFF

## まだやってないこと

- iPhone実機での確認（ネット上に置く作業＝ステップ7）
- オフライン機能（サービスワーカー）は、確認に使ったブラウザが非対応で未確認
- 本物の手書き寸法表での無料OCRの精度テスト
